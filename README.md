# GitHub Pages

The Pages workflow deploys the Apex Launch Option Builder at https://kariya.dev/apex-launch-option-builder/.

The published files in `apex-launch-option-builder/` are a static build of the source repository `kaaariyaaa/apex-launch-option-builder`. To publish later changes, rebuild with `ASTRO_BASE_PATH=/apex-launch-option-builder/` and replace the static files here. The former Pages content is no longer included in the deployment artifact.
