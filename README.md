# Additional site

The Apex launch-option builder is built from `apex-boot-option-builder/` and deployed to `/apex-boot-option-builder/`. GitHub Pages uses the Actions workflow in `.github/workflows/pages.yml`; it also republishes the existing sensitivity converter files at the repository root and `/Apex-Legends-Sensitivity-Converter/`.

Set the GitHub Actions variable `PUBLIC_GA_MEASUREMENT_ID` and secrets `GA4_PROPERTY_ID` and `GOOGLE_SERVICE_ACCOUNT_JSON` to enable analytics and daily preset rankings. Enable Pages with **GitHub Actions** as its source.
